## 🧠 Overview

**Jus_Banner** is an **interactive Python CLI tool** that lets you create custom **ASCII text banners** using the [`pyfiglet`](https://www.google.com/search?q=pyfiglet+python+examples) library with dynamic fonts and colors powered by [`colorama`](https://www.google.com/search?q=colorama+python+colored+terminal+output).  
It’s simple, user-friendly, and perfect for developers who want to add creative headers to scripts, tools, or terminal intros.

Each time the program runs, it:
- Displays a randomized banner of “Jus_Banner”.
- Prompts the user for custom text, font, and color choices.
- Renders the result in full ASCII glory!

---

## ✨ Features

✅ Random banner for the tool name each startup  
✅ Interactive prompts for text, font, and color  
✅ Hundreds of font styles from **pyfiglet**  
✅ Seven dynamic color options  
✅ Cross-platform (Linux, macOS, Windows, Termux)  
✅ Clear, aesthetic terminal experience

2️⃣ Install Dependencies
